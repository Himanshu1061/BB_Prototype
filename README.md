# बूटी & BLOOM — Ecommerce Website Prototype

Static prototype of the **बूटी & BLOOM** (Booti & Bloom) women's fashion
ecommerce storefront.

- `index.html` — the complete single-page store (home, shop, product pages,
  cart, checkout demo, account, policies, admin)
- `assets/` — product and campaign imagery

## Live demo

Served via GitHub Pages from the `main` branch (`/` root).

## Notes

- Checkout is an in-browser demo (no live payment processing). Connecting
  Razorpay keys + a backend (server-side order creation, signature
  verification, webhooks) is the launch step.
- Seeded catalog, orders and coupons (`BLOOM10`, `WELCOME15`) are demo data.
